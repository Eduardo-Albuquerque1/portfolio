📋 Sobre o Projeto
Este é um site de portfólio estático desenvolvido com HTML, CSS e JavaScript. O objetivo é apresentar o perfil profissional de Luiz Eduardo Albuquerque Alves de Lima, estudante de Ciência da Computação na CESAR School, de forma clara e elegante.

✨ Funcionalidades

Alternância de tema (claro/escuro) via botão interativo 🌙/☀️
Seções organizadas: Sobre Mim, Habilidades, Projetos, Objetivos e Contato
Layout responsivo com cards
Links diretos para GitHub e LinkedIn

Clone ou baixe este repositório

Não é necessário instalar dependências ou configurar servidor — o projeto roda localmente.

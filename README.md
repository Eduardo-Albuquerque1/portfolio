---

## 🧠 Sobre o Projeto

**Portfólio** é um site estático que apresenta o perfil profissional de Luiz Eduardo Albuquerque Alves de Lima, estudante de Ciência da Computação. O site permite:

- **Apresentação pessoal** - Quem sou e minha trajetória
- **Habilidades** - Tecnologias que estou aprendendo e praticando
- **Projetos** - Trabalhos desenvolvidos ao longo da jornada
- **Objetivos** - Metas profissionais e acadêmicas
- **Contato** - Links para e-mail, GitHub e LinkedIn

---

## 🛠️ Tecnologias

| Tecnologia   | Função                            |
|--------------|-----------------------------------|
| HTML5        | Estrutura semântica da página     |
| CSS3         | Estilização, Flexbox e Grid       |
| JavaScript   | Alternância de tema claro/escuro  |

---

## ✨ Funcionalidades

- 🌙/☀️ Alternância de tema (claro/escuro) via botão interativo
- Layout responsivo com **CSS Grid** e **Flexbox**
- Foto de perfil redonda no header
- Seções organizadas com cards animados
- Navegação entre páginas (`index.html` e `projetos.html`)
- Links diretos para GitHub, LinkedIn e projetos

---

## 📁 Estrutura de Arquivos

```
portfolio/

├── script.js        # Lógica de alternância de tema
├── README.md        # Documentação do projeto
└── img/
    └── foto.jpeg    # Foto de perfil
```

## 🚀 Como Executar

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` diretamente no navegador

> Não é necessário instalar dependências ou configurar servidor — o projeto roda localmente.
